# Dataset registry

Raw datasets are intentionally not committed to this repository.

## Dataset 1 — PVMD

https://www.kaggle.com/datasets/himani04012007/pvmd-dataset1

Purpose: visual PV fault detection.

## Dataset 2 — PV Mismatch

https://www.kaggle.com/datasets/himani04012007/pv-mismatch

Purpose: electrical/thermal PV performance degradation or supported electrical-risk task. Inspect the actual schema before defining the target.

## Dataset 3 — Solar Power Generation Data

https://www.kaggle.com/datasets/anikannal/solar-power-generation-data

Purpose: expected solar power / normal-performance modeling.

## Reproducibility

Record the dataset version/date, downloaded files, target, feature list, and preprocessing assumptions in the model metadata after each training run.
